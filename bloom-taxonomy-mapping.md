# Bloom's Taxonomy Mapping — Computer Science Curriculum

## Unit: Data Structures & Algorithms (Class 11–12 / JEE CS)

### Sorting Algorithms

| Bloom's Level | Cognitive Verbs | Learning Outcome | Diagnostic Indicator | Remediation if Gap |
|---|---|---|---|---|
| **1. Remember** | Recall, List, Name | List the steps of Bubble Sort | Can state O(n²) complexity | Flashcard drill + worked example |
| **2. Understand** | Explain, Describe, Classify | Explain WHY Merge Sort is stable | Can explain what "stable" means with an example | Concrete example with equal keys |
| **3. Apply** | Execute, Implement, Trace | Trace Merge Sort on [5,3,8,1,9,2] | Can produce correct intermediate states | Step-by-step trace worksheet |
| **4. Analyze** | Differentiate, Compare, Break down | Identify why Quick Sort degrades on sorted arrays | Can reason about pivot selection and worst case | Case study: sorted vs random input |
| **5. Evaluate** | Justify, Critique, Assess | Justify algorithm choice given constraints (space, input type) | Can defend choice with evidence | Trade-off analysis problems |
| **6. Create** | Design, Construct, Devise | Design a hybrid sort (Introsort pattern) | Can specify algorithm, justify design decisions | Open-ended project |

### Trees & Graphs

| Bloom's Level | Outcome | Diagnostic Question Stem |
|---|---|---|
| Remember | Name the 3 BST traversal orders | "List the order DFS visits nodes in in-order traversal" |
| Understand | Explain the BST property | "Why can't a BST have two nodes with the same value?" |
| Apply | Insert/delete in a BST given a diagram | "Draw the BST after inserting [10, 5, 15, 3, 7, 12]" |
| Analyze | Identify when BST degrades to O(n) | "What input sequence causes maximum BST height? Why?" |
| Evaluate | Compare BST vs Hash Table for dictionary | "When would you prefer a BST over a hash table?" |
| Create | Design a self-balancing BST variant | "Propose modifications to maintain O(log n) height" |

## Unit: Quadratic Equations (Class 10–11 Maths)

| Bloom's Level | Outcome | Question Stem | Common Misconception |
|---|---|---|---|
| Remember | Recall standard form ax²+bx+c=0 | "Write the quadratic formula" | Writing denominator as a instead of 2a |
| Understand | Explain meaning of discriminant | "What does D=0 tell us about the roots?" | Confusing D=0 (one root) with D>0 (two roots) |
| Apply | Solve x²-5x+6=0 using formula | Compute roots step by step | Sign errors in -b; forgetting ± |
| Analyze | Interpret complex roots geometrically | "What does D<0 mean for the parabola?" | Thinking "no answer" vs "complex conjugate roots" |
| Evaluate | Choose fastest method for given equation | "Should you factor or use the formula for x²-4=0?" | Always using the formula even when factoring is faster |
| Create | Construct equation from given root conditions | "Create a quadratic with roots 3+2i and 3-2i" | Not using conjugate pair theorem |
